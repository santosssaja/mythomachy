## 2. Implementasi Blockchain & Smart Contract (`MythomachyArena.sol`)

### A. Mengapa Sistem Gacha Ini Sangat "Monad Fit" & Patuh Regulasi?

1. **Kecepatan Gacha Instan (<600ms) dengan `eth_sendRawTransactionSync**`:
Di jaringan blockchain konvensional, menekan tombol *Gacha / Summon* membutuhkan waktu tunggu 12 hingga 30 detik yang merusak ketegangan animasi. Karena Monad memiliki waktu blok **0,3 detik** dan *finality* **0,6 detik**, serta menyediakan metode RPC sinkron **`eth_sendRawTransactionSync`** yang langsung mengembalikan *transaction receipt* beserta log *event* dalam satu panggilan HTTP, hasil Gacha *on-chain* muncul **seketika saat animasi cahaya kuil meledak di layar**.


2. **Eksekusi Paralel Tanpa Konflik State (*Optimistic Parallel Execution*)**:
Mesin Monad menjalankan transaksi secara paralel dan hanya mengeksekusi ulang jika ada dua transaksi yang menyentuh akun/slot penyimpanan yang sama. Oleh karena itu, seluruh data kepemilikan karakter, penghitung jaminan (*pity counter*), dan lencana kemenangan disimpan di dalam `mapping(address => PlayerData)` yang terisolasi per pemain sehingga 100% bebas dari antrean *state-lock*.


3. **Framing Kepatuhan & Strategi Pendapatan (Untuk +40 Poin Bonus Juri)**:
Sesuai panduan regulasi dari sesi *Before Blitz* dan kriteria penilaian juri untuk **Product-Market Fit (20 poin)** serta **Revenue Potential & Strategy (20 poin)**:


* Di antarmuka pengguna, sistem ini **tidak menggunakan istilah perjudian/taruhan**, melainkan **"Kuil Pemanggilan Relik"** dengan **Sistem Jaminan Pasti (*Pity System*)**: setiap pemain dijamin memperoleh salah satu dari 3 karakter *Penguasa Puncak* yang belum dimilikinya paling lambat pada pemanggilan ke-4.
* Jika hasil pemanggilan menghasilkan fragmen relik (ketika belum mendapatkan karakter baru), pemain otomatis memperoleh **Energi Relik** yang meningkatkan statistik pertahanan di mode latihan melawan Bot.



### B. Kode Lengkap Smart Contract (`src/MythomachyArena.sol`)

Batas ukuran kontrak di Monad mencapai **256KB** (lebih dari 10 kali lipat batas Ethereum), sehingga seluruh logika Gacha, *Pity System*, Ruang Tunggu Publik/Privat, dan Pengesahan Pertandingan dapat digabungkan dalam satu kontrak tunggal tanpa *proxy*:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

contract MythomachyArena {
    // Bit 0..7 (nilai desimal 255 = 0x00FF) terbuka otomatis untuk 8 karakter pertama.
    // Bit 8 = Gilgamesh (ID 8), Bit 9 = Nyi Roro Kidul (ID 9), Bit 10 = Chronos-Aethelgard (ID 10).
    uint16 public constant DEFAULT_UNLOCKED_MASK = 0x00FF; // 0000000011111111 dalam biner
    uint16 public constant ALL_UNLOCKED_MASK = 0x07FF;     // 0000011111111111 (11 karakter)

    struct PlayerProfile {
        uint16 unlockedMask;
        uint8 pityCounter;
        uint32 relicShards;
        uint32 victories;
        uint32 matchesPlayed;
    }

    struct Room {
        bytes6 roomCode;
        address host;
        address challenger;
        uint8 mapId;
        bool isPrivate;
        bool isActive;
        address winner;
    }

    mapping(address => PlayerProfile) private profiles;
    mapping(bytes6 => Room) public rooms;
    bytes6[] public publicRoomCodes;

    eventSummonExecuted(
        address indexed player,
        bool isNewLegend,
        uint8 legendId,
        uint32 totalRelicShards,
        uint16 updatedMask
    );
    event RoomCreated(bytes6 indexed roomCode, address indexed host, bool isPrivate, uint8 mapId);
    event RoomJoined(bytes6 indexed roomCode, address indexed challenger);
    event MatchSettled(bytes6 indexed roomCode, address indexed winner, uint8 hostLegend, uint8 challengerLegend);

    // Mengambil status profil pemain (otomatis mengaktifkan 8 karakter awal jika akun baru)
    function getPlayerProfile(address player) external view returns (
        uint16 unlockedMask,
        uint8 pityCounter,
        uint32 relicShards,
        uint32 victories,
        uint32 matchesPlayed
    ) {
        PlayerProfile memory p = profiles[player];
        uint16 mask = p.unlockedMask == 0 ? DEFAULT_UNLOCKED_MASK : (p.unlockedMask | DEFAULT_UNLOCKED_MASK);
        return (mask, p.pityCounter, p.relicShards, p.victories, p.matchesPlayed);
    }

    // Fungsi Gacha On-Chain ("Kuil Pemanggilan") dengan Pity Guarantee di tarikan ke-4
    function summonApexLegend(uint256 clientSeed) external payable returns (bool isNewLegend, uint8 legendId) {
        PlayerProfile storage p = profiles[msg.sender];
        if (p.unlockedMask == 0) {
            p.unlockedMask = DEFAULT_UNLOCKED_MASK;
        }

        p.pityCounter += 1;

        // Pseudo-random on-chain menggunakan prevrandao, timestamp, sender, dan nonce/pity
        uint256 rand = uint256(
            keccak256(
                abi.encodePacked(
                    block.prevrandao,
                    block.timestamp,
                    msg.sender,
                    p.pityCounter,
                    p.relicShards,
                    clientSeed
                )
            )
        );

        // Peluang dasar 35% mendapat karakter Apex, ATAU 100% pasti dapat jika pityCounter >= 4
        bool hitJackpot = (rand % 100 < 35) || (p.pityCounter >= 4);

        if (hitJackpot && (p.unlockedMask & ALL_UNLOCKED_MASK) != ALL_UNLOCKED_MASK) {
            p.pityCounter = 0;

            // Cari karakter Apex (ID 8, 9, 10) yang belum dimiliki pemain agar tidak duplikat
            uint8[3] memory apexIds = [uint8(8), uint8(9), uint8(10)];
            uint8 startIdx = uint8((rand >> 8) % 3);

            for (uint8 i = 0; i < 3; i++) {
                uint8 candidate = apexIds[(startIdx + i) % 3];
                if ((p.unlockedMask & uint16(1 << candidate)) == 0) {
                    p.unlockedMask |= uint16(1 << candidate);
                    emitSummonExecuted(msg.sender, true, candidate, p.relicShards, p.unlockedMask);
                    return (true, candidate);
                }
            }
        }

        // Jika belum mendapat karakter baru (atau seluruh 11 karakter sudah dimiliki), berikan Relic Shards
        uint8 pickedId = uint8(8 + ((rand >> 16) % 3));
        p.relicShards += 25;

        // Jika terkumpul 75 Relic Shards, otomatis tukarkan dengan 1 karakter Apex yang belum terbuka
        if (p.relicShards >= 75 && (p.unlockedMask & ALL_UNLOCKED_MASK) != ALL_UNLOCKED_MASK) {
            for (uint8 candidate = 8; candidate <= 10; candidate++) {
                if ((p.unlockedMask & uint16(1 << candidate)) == 0) {
                    p.relicShards -= 75;
                    p.pityCounter = 0;
                    p.unlockedMask |= uint16(1 << candidate);
                    emitSummonExecuted(msg.sender, true, candidate, p.relicShards, p.unlockedMask);
                    return (true, candidate);
                }
            }
        }

        emitSummonExecuted(msg.sender, false, pickedId, p.relicShards, p.unlockedMask);
        return (false, pickedId);
    }

    function createRoom(bytes6 roomCode, bool isPrivate, uint8 mapId) external {
        require(rooms[roomCode].host == address(0), "Room code already used");
        rooms[roomCode] = Room({
            roomCode: roomCode,
            host: msg.sender,
            challenger: address(0),
            mapId: mapId,
            isPrivate: isPrivate,
            isActive: true,
            winner: address(0)
        });
        if (!isPrivate) {
            publicRoomCodes.push(roomCode);
        }
        emit RoomCreated(roomCode, msg.sender, isPrivate, mapId);
    }

    function joinRoom(bytes6 roomCode) external {
        Room storage r = rooms[roomCode];
        require(r.isActive, "Room not active");
        require(r.challenger == address(0), "Room full");
        r.challenger = msg.sender;
        emit RoomJoined(roomCode, msg.sender);
    }

    function settleMatch(bytes6 roomCode, address winner, uint8 hostLegend, uint8 challengerLegend) external {
        Room storage r = rooms[roomCode];
        if (r.isActive) {
            r.isActive = false;
            r.winner = winner;
        }
        PlayerProfile storage wp = profiles[winner];
        if (wp.unlockedMask == 0) wp.unlockedMask = DEFAULT_UNLOCKED_MASK;
        wp.victories += 1;
        wp.matchesPlayed += 1;
        wp.relicShards += 15; // Hadiah pecahan relik setiap menang pertandingan
        emit MatchSettled(roomCode, winner, hostLegend, challengerLegend);
    }
}

```

## 3. Saran Pengembangan Unik ("Secret Sauce" Pembeda Juara 1)

Agar aplikasi ini menonjol secara teknis di hadapan juri dan terhindar dari risiko aset eksternal yang gagal dimuat saat demo panggung 3 menit:

1. **Rigging Artikulasi 3D Prosedural dengan Preset Gerakan (Zero Broken External `.glb`)**:
Jangan mengunduh model 3D eksternal berukuran besar yang berisiko gagal dimuat di jaringan Wi-Fi lokasi. Bangun ke-11 karakter menggunakan **Rigging Hierarkis Prosedural di Three.js** (`Group` untuk Torso, Kepala, Bahu, Lengan Atas/Bawah, Senjata, Kaki, dan Sayap Artikulasi khusus untuk **Garuda** serta **Quetzalcoatl**). Buat mesin animasi berbasis fungsi sinusoida dan *keyframe interpolation* untuk 6 preset gerakan:
* `IDLE` (Napas naik-turun + ayunan senjata/sayap perlahan)
* `WALK` (Ayunan kaki dan tangan berlawanan fase)
* `DASH` (Condong ke depan 35 derajat + jejak bayangan cahaya)
* `BASIC_ATTACK` (Ayunan sendi bahu dan senjata cepat)
* `SKILL_CAST` (Lompatan/pengangkatan tangan + gelombang cincin energi 3D)
* `ULTIMATE` (Efek kamera sedikit mendekat + ledakan partikel geometri)


2. **Synthesizer Suara Pertarungan & Gacha Berbasis Web Audio API**:
Tanpa perlu satu pun file `.mp3` eksternal, bangun modul `MythAudioEngine` menggunakan **Web Audio API** (`AudioContext`, `OscillatorNode`, `BiquadFilterNode`, dan *Noise Buffer*):
* Suara dentuman pukulan berat (*low-pass filtered triangle wave* 110Hz -> 35Hz).
* Suara tebasan pedang/angin (*band-pass white noise sweep*).
* Suara arpeggio kristal naik (*harmonic sine/triangle chord progression*) saat pemain menekan tombol **Panggil Legenda (Gacha)**, diakhiri akor emas megah ketika mendapatkan salah satu dari 3 karakter *Penguasa Puncak*.


3. **Sinkronisasi State Tunggal untuk Perpindahan Mode 2D & 3D Secara Instan**:
Simpan koordinat pertarungan (`x, y, z, hp, cooldowns, state`) dalam satu objek `ArenaSimulation`. Saat pemain menekan tombol `Mode 2D` atau `Mode 3D` (bahkan di tengah pertarungan sedang berlangsung!), pertarungan tidak diulang dari awal—kamera langsung melakukan transisi proyeksi secara mulus sambil tetap mempertahankan logika **pohon transparan otomatis (`opacity: 0.20`)** dan **fisika anti-tembus antar-karakter**.
4. **Panel "Bukti Verifikasi Panggung" Khusus di Mode Demo**:
Sesuai instruksi *slide* halaman 12 (*"SAY IT OUT LOUD: Mention your repo link, contract address, live URL and deployment during the pitch"*), ketika **Mode Demo** diaktifkan dari menu Pengaturan, tampilkan bilah khusus di bagian bawah layar yang memuat tombol 1-klik untuk memicu transaksi *live on-chain*, menampilkan waktu respon RPC `eth_sendRawTransactionSync` dalam milidetik, serta menampilkan alamat kontrak dan URL secara jelas agar mudah kamu bacakan di panggung.
